## VesselSSH

VesselSSH is an open-source DevOps tool designed to provide a desktop-like experience directly in your browser. It brings server management and development tools together in one place, allowing users to interact with their server through a unified interface instead of switching between multiple applications.

> [!NOTE]
> VesselSSH is currently under active development. At this stage, we do not recommend using it on servers shared by multiple users.\n
> Although VesselSSH has its own authentication system, its permissions and access controls are not yet user-specific. For now, it is intended for single-user environments where one trusted user manages the server.

The goal of VesselSSH is to make server management and development simpler, more accessible, and more convenient.
